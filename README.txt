ALEKSANDRA M. SZUBA — STOPKA GMAIL — PAKIET TESTOWY

1. Utwórz publiczne repozytorium GitHub: ola-email-signature
2. Wgraj do głównego katalogu repozytorium:
   - index.html
   - folder assets/
3. Wejdź w Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Zapisz. Po chwili GitHub poda adres strony.
7. Otwórz stronę → kliknij „Kopiuj stopkę”.
8. Gmail → Ustawienia → Zobacz wszystkie ustawienia → Ogólne → Podpis.
9. Wklej zwykłym Ctrl/Cmd+V.
10. Wyślij test na Gmail/Outlook i sprawdź telefon.

WAŻNE:
- grafiki są tymczasowo hostowane przez GitHub Pages;
- później przeniesiemy je na domenę Oli i podmienimy ścieżki;
- LinkedIn / Instagram / Facebook są podlinkowane;
- telefon, e-mail, WWW, logo i social media są klikalne.
